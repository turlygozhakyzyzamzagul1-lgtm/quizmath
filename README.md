# QuizMath — бастапқы веб-жоба

Бұл жоба мұғалімдерге арналған QuizMath платформасының іске қосылатын веб-құрылымы.

## Құрамында
- Қазақ тіліндегі басты бет және Google арқылы кіру батырмасы
- Мұғалім кабинеті
- Тест, сәйкестендіру, бөлшектер, жиындар, пайыздар бөлімдері
- Ойын құрастыру және алдын ала қарау
- 3D фигуралар зертханасының демонстрациялық моделі
- Мұғалім басқаратын жарыс ұпайлары
- Supabase-ке ойын сақтау интеграциясының бастапқы коды

## Іске қосу және Google авторизациясын баптау

1. https://supabase.com сайтында жоба жасаңыз.
2. Project Settings → API бөлімінен Project URL және anon/public key көшіріңіз.
3. `public/index.html` файлын ашып, `SUPABASE_URL` және `SUPABASE_ANON_KEY` мәндерін ауыстырыңыз.
4. Supabase → SQL Editor бөліміне `supabase/schema.sql` мазмұнын енгізіп, орындаңыз.
5. Supabase → Authentication → Providers → Google бөлімінде Google провайдерін қосыңыз.
6. Google Cloud Console ішінде OAuth Client жасаңыз. Client ID және Client Secret мәндерін Supabase Google provider баптауына енгізіңіз.
7. Supabase Authentication → URL Configuration ішіне жарияланған сайттың URL-ын Redirect URL ретінде қосыңыз.
8. `public/index.html` файлын статикалық хостингке (мысалы, Netlify немесе Vercel) жариялаңыз.

## Маңызды шектеулер
- Google OAuth нақты кілттерсіз жұмыс істемейді.
- Бұл — бастапқы нұсқа. Сақтау Supabase-ке жалғанғаннан кейін әр мұғалімнің ойындары өз аккаунтына сақталады.
- Қазір редактор бір сұрақты тест үлгісін сақтайды; толық көпсұрақты редактор, толыққанды сәйкестендіру, бөлшектер/жиындар/пайыздарға арналған арнайы редакторлар кейін кеңейтілуі тиіс.
- 3D көрініс демонстрациялық кубтан тұрады; нақты 3D геометрия және жазбадан жинау анимациясы толық іске асырылмаған.
- Жарыс әзірге бір мұғалім экранындағы ұпай санау үлгісі; оқушылардың бірнеше құрылғыдан қосылатын real-time жарысы үшін қосымша backend қажет.

Қауіпсіздік: Supabase `service_role` кілтін браузерге ешқашан салмаңыз. Тек anon/public key қолданыңыз және RLS саясаттарын қосулы ұстаңыз.
